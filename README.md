# christmas-tree · v17.6

一个单文件的圣诞树页面：粒子针叶、螺旋灯串、旋转视角、飘雪与树顶许愿星，支持手势（含摄像头识别）实时驱动粒子。

## 交互

- 打开 `index.html` 即可预览（摄像头手势需用 http/https 打开，`file://` 下浏览器会禁用摄像头）
- **拖动（鼠标或单指）**：在指针处生成风场，1600 颗针叶粒子被径向推开并卷成涡旋，雪花被气流带走，抬手后风势自然衰减
- **横向甩动**：带动整棵树加速旋转，快速拖动会洒出星屑
- **双指捏合 / 滚轮**：缩放视角（0.6×–1.5×），放大时标题自动隐去
- **点击树顶星星**：星屑迸发、加速旋转、雪花重新落下

## 摄像头手势（MediaPipe HandLandmarker）

点右下角「启用手势」，授权摄像头后按提示把手放进取景框：

- **张开手掌**：手心位置驱动风场，掌位移动即起风，径向推开针叶与雪花
- **握拳**：粒子向手心吸附聚拢
- **拇指与食指捏合**：更强的吸附涡旋，镜头同时微微推近
- **横向挥手**：加速树体旋转

所有画面只在本机推理，不上传。运行时与模型已随仓库打包（`vendor/mp/`），不依赖 jsDelivr 等 CDN，断网/国内网络也能加载。
