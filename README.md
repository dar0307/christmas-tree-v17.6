# christmas-tree · v17.6

一个单文件的圣诞树页面：粒子针叶、螺旋灯串、旋转视角、飘雪与树顶许愿星，支持手势实时驱动粒子。

- 打开 `index.html` 即可预览
- **拖动（鼠标或单指）**：在指针处生成风场，1600 颗针叶粒子被径向推开并卷成涡旋，雪花被气流带走，抬手后风势自然衰减
- **横向甩动**：带动树体加速旋转，快速拖动会洒出星屑
- **双指捏合 / 滚轮**：缩放视角（0.6×–1.5×），放大时标题自动隐去
- **点击树顶星星**：星屑迸发、加速旋转、雪花重新落下

纯原生 Canvas 2D，无任何外部依赖，可直接部署到 GitHub Pages。
